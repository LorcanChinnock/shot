# Settings

Read this before adding or changing a preference.

- Keys and defaults live in ShotCore `Preferences`.
- `SettingsStore` is an `@Observable` cache, and views use its `@Setting(key)` wrapper (never `@AppStorage`).
- The Settings window (`SettingsView.swift`) has a sidebar of `SettingsSection`s, each with its icon tint (`Theme.SidebarTint`), and the open section's rows on the right. `SettingsNavigation` holds the section, the search and the keyboard state, and `shot://settings?section=` opens a section.
- Open Settings or the gallery through `ShotWindowRouter`, never a window controller directly. While the hidden `PreferenceKey.oneWindow` is on (`defaults write dev.lorcan.Shot.dev oneWindow -bool YES`, #1460), it opens `MainWindowController`, one window that shows the library or the settings pages (`MainWindowNavigation.page`), with "‹ Library" and a Settings row linking the two sidebars (`\.inMainWindow`). Otherwise it opens `SettingsWindowController` or `GalleryWindowController`, as before. Both stay until one window becomes the default.
- In the one window, one search field covers settings and captures. `MainWindowView` keeps `GalleryModel.query` and `SettingsNavigation.query` the same, and ShotCore's `MainWindowSearch.content` decides what shows. On the library, `MainWindowResults` (matching settings with their controls, then up to eight captures) covers the grid only when `SettingsMatchProbe` finds a setting, so a search for captures filters the grid as before. On the settings pages, any search shows it. "Show all in library" goes to the filtered grid until the search changes.
- A preference's row goes in its section's view as a `SettingRow` or `ToggleRow` inside a `SettingsCard`. The search at the top of the sidebar finds it with no extra work: ShotCore's `SettingsSearch.matches` looks for every typed word in the row's name and description and in its group's and section's names, so a clear name and description are what make it findable. While a search holds a word, the window lists the matching rows from every section, and a card hides when none of its rows match.
